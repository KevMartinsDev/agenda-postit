# Agenda Post-it
 
Uma agenda desktop em Java com lembretes que viram post-its flutuantes na tela.
 
Esse é um projeto de estudo que estou desenvolvendo de forma iterativa. A ideia é começar simples e ir evoluindo aos poucos, praticando OOP, testes e boas práticas no caminho — em vez de tentar fazer tudo de uma vez.
 
## Status
 
Em desenvolvimento — atualmente na v0.1
 
## Versões planejadas
 
- **v0.1** — Núcleo no console: criar, listar, editar e concluir tarefas
- **v0.2** — Persistência local dos dados
- **v0.3** — Notificações por horário
- **v0.4** — Interface gráfica
- **v0.5** — Post-its flutuantes na área de trabalho
  
## Tecnologias
 
- Java 21
- JUnit 5
